# 19. Operación y soporte (runbook mínimo, `docs/OPERACION.md`)

- Cómo ver si el sitio está bien (`/api/health`, panel de Cloudflare, estado de Neon).
- Qué hacer si **la API falla**: el menú cacheado sigue; el cliente puede pedir por el botón de WhatsApp directo; el restaurante atiende desde WhatsApp y registra después.
- Qué hacer si **no llegan pedidos**: revisar panel, internet del local, volumen del sonido, permisos del navegador.
- Restablecer la contraseña de un usuario; desactivar un domiciliario que dejó de trabajar.
- Restauración de base de datos desde un punto en el tiempo (pasos exactos).
- Rotación de secretos (calendario cada 6 meses o ante sospecha).
- A quién llamar y qué datos dar (versión, hora, código de pedido).
